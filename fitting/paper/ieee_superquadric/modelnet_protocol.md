# ModelNet40 single-superquadric protocol

- Source: official ModelNet40 OFF meshes and official `test` split.
- Categories: bottle, bowl, cone, flower_pot, glass_box, vase, xbox.
- Selection: 20 models per category using seed `20260715`.
- Normalization: subtract the mesh bounding-box center and divide by its bounding-box diagonal.
- Pose: apply one reproducible uniform random rotation in SO(3) to each normalized mesh.
- Input: sample 5,000 points from triangles in proportion to triangle area.
- Reference: independently sample 20,000 points from the same normalized mesh.
- Fitting and reference samples are disjoint.
- Report normalized Chamfer distance and F-score with threshold 0.01 of the pre-rotation source bounding-box diagonal.
- Treat results as one-superquadric approximation, not exact 11-parameter recovery, because ModelNet meshes are not generated by superquadrics.
