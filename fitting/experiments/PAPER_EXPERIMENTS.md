# 论文实验计划：GD + MM 非经典几何模型拟合

## 论文标题（草案）

> **Gradient-Based Optimization for Robust Fitting of Non-Classical Geometric Models**
> — 优化器贡献：用 GD 替代启发式搜索，MM 评分保持鲁棒性
> — 或突出 MM：**Mean Measure-Guided Gradient Descent for Multi-Instance Geometric Fitting**

---

## 核心叙事

```
张老师 PR 2019:  MM评分 + Cuckoo Search → 鲁棒但慢
张老师 AAAI 2019: MM评分 + 强化学习 → 更快但仍需大量采样
我们:            MM评分 + 梯度下降 → 高效、可扩展、多模型
```

**三个贡献点：**
1. **GD 作为优化器** — 比 CS/CCO/ALA 更快收敛到更高 MM score
2. **MM 评分驱动模型选择** — 无阈值、模型无关的鲁棒评估
3. **跨模型验证** — 同一框架在曲线/曲面/字符上均有效

---

## 基线方法

| 优化器 | 来源 | 类型 |
|--------|------|------|
| **CCO** | 合作协同优化 | 启发式 |
| **CS** | Cuckoo Search (PR 2019) | 启发式 |
| **ALA** | 自适应学习算法 | 启发式 |
| **GD (ours)** | 梯度下降 + Adam | 梯度 |

**所有优化器都用 MM 评分选最优模型**，只比优化器效率。

---

## 实验矩阵

### 实验 1：收敛效率对比（核心实验）

**数据：** 3个模型 × 3个数据集 = 9组

| 模型 | 数据集 | 变量数 | 说明 |
|------|--------|--------|------|
| CurveRule (Spiral) | KSR42 road boundary | 9 | 道路曲线 |
| NURBSSurfaceRule | Bunny 150k | 72-144 | 曲面拟合 |
| CharacterRule | MNIST corrupted | ~50 | 字符拟合 |

**对比：** CCO vs CS vs ALA vs GD
**指标：** MM score vs 迭代次数曲线，最终 MM score，收敛时间

**预期：** GD 比 CS 快 5-10x 达到同等 score，且最终 score 更高（GD 连续优化 vs CS 离散采样）

**图：** 4条曲线（4个优化器），x轴=时间(wall clock)，y轴=MM score

---

### 实验 2：噪声鲁棒性

**数据：** Bunny + 高斯噪声 σ ∈ {0.005, 0.01, 0.02, 0.05}

| 噪声水平 | CCO | CS | ALA | GD (ours) |
|---------|-----|-----|-----|-----------|
| σ=0.005 | | | | |
| σ=0.01 | | | | |
| σ=0.02 | | | | |
| σ=0.05 | | | | |

**指标：** 各噪声水平下的 MM score 保留率 (= score_noisy / score_clean)
**预期：** GD 在所有噪声水平下保持最高 score，因为 GD 的平滑 loss 天然抗噪

---

### 实验 3：离群点鲁棒性

**数据：** Bunny + 随机离群点 {10%, 20%, 40%, 60%}

| 离群率 | CCO | CS | ALA | GD (ours) |
|--------|-----|-----|-----|-----------|
| 10% | | | | |
| 20% | | | | |
| 40% | | | | |
| 60% | | | | |

**关键：** MM 评分本身对离群点鲁棒（model→data方向+离群点不是最近邻）
**预期：** 所有方法的 MM score 在离群率<40%时相对稳定；GD 在 60% 时仍优于其他

---

### 实验 4：缺失数据鲁棒性

**数据：** 部分球面（切掉30%）、双补丁带间隙

| 场景 | CCO | CS | ALA | GD (ours) |
|------|-----|-----|-----|-----------|
| 部分球面 | | | | |
| 双补丁 | | | | |

**指标：** 缺失区域内的拟合点数量 + MM score
**预期：** GD 不会盲目填充缺失区域（因为 MM 的 model→data 误差惩罚）

---

### 实验 5：多实例拟合

**数据：** 多物体场景（如 ABC dataset 的多个曲面）

| 实例数 | CCO | CS | ALA | GD (ours) |
|--------|-----|-----|-----|-----------|
| 2 | | | | |
| 4 | | | | |
| 8 | | | | |

**指标：** 每个实例的 MM score，实例间重叠率，总覆盖率
**预期：** GD 的贪心多实例策略在 4-8 实例时优于其他方法

---

### 实验 6：评分一致性（消融）

**问题：** MM 评分和 NPRE 评分选出的最优模型是否一致？

**数据：** 所有实验的中间结果

| 场景 | NPRE选最优 | MM选最优 | 一致性 |
|------|-----------|---------|--------|
| 干净数据 | | | 预期 >90% |
| 噪声数据 | | | 预期 >80% |
| 离群点 | | | 预期 >70%（MM更鲁棒） |
| 缺失数据 | | | 预期 MM 选出的模型更好 |

**预期：** 在干净数据上两者一致；在损坏数据上 MM 更可靠

---

### 实验 7：跨模型通用性验证

**问题：** 同一个 GD+MM 框架，换模型不换代码，是否都有效？

**方法：** 对 CurveRule、NURBSSurfaceRule、CharacterRule 分别跑实验 1
**不需要改任何 fitter 代码**，只改 config 的 rule_class

**预期：** 三种模型上 GD 都优于 CS
